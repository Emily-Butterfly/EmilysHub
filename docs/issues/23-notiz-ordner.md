# 23 – Verschachtelte Notiz-Ordner

**Etappe:** 6 – Notizen  
**Typ:** Feature  
**Art:** 🤖 AFK – kann ohne Rückfragen umgesetzt werden  
**Spezifikation:** [SPEC.md](../../SPEC.md) §7  
**GitHub-Issue:** #23  
**Blockiert durch:** [22 – Notiz-Tabs & Markdown-Notizen](22-notiz-tabs-markdown.md)

## Was gebaut wird

Innerhalb eines Tabs lassen sich Ordner beliebig tief verschachteln.

## Akzeptanzkriterien

- [ ] Ordner anlegen, umbenennen, beliebig tief verschachteln, auf-/zuklappen
- [ ] Pfad-Anzeige (z. B. „Arabisch › Grammatik › Verben“) mit Rücksprung
- [ ] „Verschieben nach…“ für Notizen und Ordner, auch zwischen Tabs; Zyklus-Schutz
- [ ] Ordner löschen mit Rückfrage: Inhalt eine Ebene höher verschieben oder mitlöschen
- [ ] Sortierung pro Ordner: Name / letzte Änderung / manuell
